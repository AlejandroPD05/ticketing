Modelo de datos

Nada de CHECK embebidos: roles, prioridades y estados son tablas lookup con clave foránea, y Transiciones_Estado codifica en base de datos qué cambios de estado son legales.

Ciclo de vida del ticket

Diez transiciones permitidas, validadas por la capa de servicios contra el catálogo en memoria.

Abierto Recién creado, en cola
→
En_Progreso En manos de un técnico
⇄
Pendiente_Usuario Esperando al usuario
→
Resuelto Solución aplicada, fija cierre
→
Cerrado Confirmado por el usuario
⇄
Reapertura → En_Progreso · borra fecha_cierre
Origen Destino Quién lo ejecuta Motivo
Abierto En_Progreso Técnico / admin El técnico se hace cargo
Abierto Pendiente_Usuario Técnico / admin Se pide aclaración al reportero
En_Progreso Abierto Técnico / admin Se devuelve a la cola
En_Progreso Pendiente_Usuario Técnico / admin Falta información del usuario
En_Progreso Resuelto Técnico / admin Incidencia solucionada: empieza el reloj de resolución
Pendiente_Usuario En_Progreso Técnico / admin El usuario responde
Pendiente_Usuario Abierto Técnico / admin Se reinicia la indagación
Resuelto Cerrado Usuario creador El usuario confirma la solución
Resuelto En_Progreso Técnico / admin Reapertura: no era la solución
Cerrado En_Progreso Técnico / admin Reapertura tardía por soporte

Arquitectura Java

JDBC sin framework: la CLI no contiene SQL ni reglas de negocio.

CLI

Menús por rol para crear, asignar, transicionar, comentar, valorar y consultar informes.

Servicios

TicketService concentra permisos, máquina de estados, SLA y auditoría.

DAO / JDBC

Patrón unit-of-work: los escritos reciben la Connection abierta; las lecturas abren la suya.

MySQL 8

Vistas para los KPIs, índices sobre las búsquedas calientes y constraints a nivel de datos.

Paquetes

  • com.royaltown.helpdesk.model—Ticket, Usuario, Estado, Prioridad y Catálogo: registros inmutables
  • com.royaltown.helpdesk.dao—TicketDao, HistorialDao, ReporteDao… PreparedStatement y unit of work
  • com.royaltown.helpdesk.service—TicketService, AuthService, ReporteService y CatalogoService
  • com.royaltown.helpdesk.cli—Main y Consola: menús por rol, tablas alineadas, captura de excepciones
  • com.royaltown.helpdesk.util—ConexionDB, PasswordHash (bcrypt) y Transaccion (todo o nada)
  • com.royaltown.helpdesk.exception—HelpdeskException: violaciones de regla de negocio
